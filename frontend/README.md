# Tick Tock Next.js — Stage 5

This is the new React/Next.js frontend.

Install:
```bash
npm install
```

Run:
```bash
npm run dev
```

Optional API URL:
```bash
NEXT_PUBLIC_API_URL=http://localhost:8000
```

IMPORTANT:
- Keep the existing Flask frontend.
- Keep the existing FastAPI backend.
- This stage only adds `frontend/ticktock-next`.
- Do not delete `app.py`, `templates`, `static`, or backend files.
