# Tick Tock Super Features

This build adds a single **✨ Super** button on the home feed.

Included: Stories, Direct Messages, Close Friends, Reposts, Trending hashtags, recommendations, creator insights, and an AI Content Studio.

Existing routes and AI features are preserved. AI Content Studio requires `OPENAI_API_KEY` in Render. No API key is placed in browser code.

For stories, the current UI accepts a media URL. Use URLs already stored in your own Supabase/approved media storage; do not hotlink or republish copyrighted social-media content without permission.
