# Tick Tock — Sellable Product Roadmap

- Lazy video loading
- Pause non-visible videos
- Release distant media buffers
- Render health endpoint `/healthz`

- Responsive viewport and full-height reel feed
- Mouse/touch scrolling and native video controls

## Stage 5 — Security
- Environment-based secrets
- Secure session cookies
- Rate limiting
- Security headers
- Same-origin checks
- Admin credentials outside source code

- `/admin/login`
- User/video/report statistics
- Report status management
- Video removal

## Stage 8 — Public launch pages
- `/about`
- `/privacy`
- `/terms`
- `robots.txt`
